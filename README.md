# 📘 Attendance Compliance Mini Test

This repository contains a **browser‑based quiz application** designed to test and improve employees’ understanding of company attendance rules, labor regulations, and the correct use of the **AKASHI** attendance management system.  
The quiz runs entirely in the browser using **HTML + JavaScript**, with no external dependencies.

---

## 🚀 Features

### ✔ Randomized Quiz Generation
- The app contains a large set of predefined questions covering:
  - 36 Agreement (36協定) and special clauses  
  - AKASHI basic operations  
  - Attendance rules and general labor compliance  
  - Breaks, holidays, compensatory leave  
  - Overtime and work-hour regulations  
- Questions are **randomly shuffled** each time.
- Users can choose how many questions to answer (1 to total available).

### ✔ Automatic Scoring & Pass/Fail Judgment
- The score is calculated automatically.
- Passing requires **80% or higher**.
- Supports both **single-choice** and **multiple-choice** questions.

### ✔ Detailed Answer Review
After completing the quiz, users can view:
- Their selected answers  
- The correct answers  
- A correctness indicator (✔ Correct / ✖ Incorrect)

### ✔ Certificate Download
If the user passes:
- A **text-based certificate** is generated dynamically.
- The certificate includes:
  - Name  
  - Score  
  - Pass/fail result  
  - Issue date  
- The certificate opens in a new tab for saving or copying.

### ✔ Simple, Self‑Contained Implementation
- No frameworks or libraries required.
- All logic is implemented in a single HTML file using vanilla JavaScript.

---

## 🖥 How to Use

1. Open `index.html` in any modern browser.
2. Enter your name.
3. Select the number of questions to answer.
4. Click **Start Quiz**.
5. Complete all questions.
6. View your score and answer breakdown.
7. If you pass, download or save your certificate.

---

## 📱 Notes for iPhone Users
When viewing the certificate:
- Long‑press the displayed text  
- Copy and paste it into Notes or another app to save it

(This is due to iOS restrictions on direct file downloads.)
